# T-44 — Performans ve hata yönetimi doğrulaması

> Ultracode iş akışı: 4 paralel denetim (çizim + bellek · açılış + hata yönetimi · okuma maliyeti + önbellek · çevrimdışı) → her bulguya bağımsız şüpheci doğrulama → 3 paralel uygulama grubu → bütünleme + kapı. Kaynak: roadmap T-44; PLAN R-02 (kapak SVG maliyeti), Q-12 (çevrimdışı), §21 #11 (profil ölçümü cihaz ister); T-43 raporu (MGT-02 / 06 / 08 çevrimdışı yazma testi eksik).

## 1. Kapsam
- **Çizim / bellek:** liste kaydırma (CLB-01 kapakları, akış görselleri), `GuCover` / desen SVG maliyeti (R-02: 26 kapak, 700 daire), gereksiz yeniden çizim, görsel çözme boyutu, dinleyici / denetleyici sızıntısı.
- **Açılış:** `runApp` öncesi bekleyen işler, Remote Config / oturum çözümü sırası, ilk kare.
- **Hata yönetimi:** `FlutterError.onError`, `PlatformDispatcher.onError`, `runZonedGuarded`, `ErrorWidget.builder` üretim davranışı, Crashlytics (release'te açık, emülatör / debug'da kapalı), yutulan hata.
- **Okuma maliyeti + önbellekten okuma** (kullanıcıya önceden söylendi): sorgu sınırları, N+1 okuma, ekran başına yinelenen okuma; nadir değişen veride (kulüp listesi, kulüp herkese açık belgesi, sabit tablolar, başka kullanıcının herkese açık profili) bellek içi kısa süreli önbellek, çek-yenile ve kendi yazımın önbelleği geçersiz kılar.
- **Çevrimdışı (Q-12):** her yazma yolu TST-24 engeli; okuma önbellekten; SYS-03 / bant; eksik testler (MGT-02 / 06 / 08).

## 2. Kullanıcıya profil çıktısı
Gerçek cihaz ölçümü (profile modu) simülatörde yapılamaz: `integration_test/perf/` (açılış, CLB-01 kaydırma, akış kaydırma — `traceAction` + zaman çizelgesi özeti) + `test_driver/` + komutlar `docs/reports/T-44-perf.md`. Kullanıcı T-46'da gerçek cihazda koşar (yeni borç). SVG ayrıştırma mikro ölçümü (`benchmark/`, kapıya girmez) bu task'ta koşulur ve rapora yazılır.

## 3. Bitti
`bash tool/quality_gate.sh --task T-44` yeşil → commit `perf(T-44): performans ve hata yönetimi` → PR → merge.

## 4. Sonuç
1. **Denetim:** 4 alanda 37 bulgu → 28 doğrulandı ve uygulandı, 9 elendi (gerekçeler CD-167 (6)). Görünüm ve golden değişmedi.
2. **Çizim / bellek:** FED-01 tembel sliver — 60 görselli akışta kurulan kart / istenen adres 60 / 60 → 3 / 3; tek beğenide yeniden kurulan kart 20 → 6; adres gelince yeniden kurulum sekme + tüm kartlar → yalnızca ilgili kart. 40 dp avatar (@3x) 1600 × 1200 → 160 × 120 çözülür (≈ 7,7 MB → ≈ 77 KB).
3. **R-02 SVG ölçümü (debug JIT):** 26 kapak ilk yükleme 50,0 ms, önbellekli 4,5 ms; "dots" kapak ≈ 7 ms ilk / 0,53 ms önbellekli → ayrıştırma takılma kaynağı değil; raster maliyeti cihazda ölçülecek (W-108).
4. **Okuma maliyeti:** bellek içi önbellek (kulüp 5 dk, profil 10 dk; yazım duyurusu + oturum değişimi geçersiz kılar), `listMine` süzgeci, `savedAmong` (sayfa başına 20 → 1 okuma), EVT-01 katılım sonrası tam yeniden okuma → 2 okuma; CLB-03 örnek ziyaret ≈ 70 → 18 (ilk) / 10 (tekrar). 3 yeni bileşik indeks (konuşlandırma kullanıcıda).
5. **Hata yönetimi:** kuyruktaki yazımın süre aşımı başarı (yinelenen kayıt kalktı); açılış en kötü 15+15+10 → 3+3+10 = 16 sn (< 20 sn splash); beklenmeyen hatalar Crashlytics `nonFatal`, uid bağlı; toplama yalnızca release + production.
6. **Çevrimdışı (Q-12):** okuma süre aşımında kalıcı önbellek, önbellekte olmayan belge `unavailable`, 18 listede SYS-03 + yeniden bağlanınca sessiz yükleme, görsel adresleri cihazda (en çok 200), DebugMenu simülasyonu Firestore ağını kapatır, çevrimdışı çıkışta push jetonu temizliği yeniden denenir.
7. **Testler:** ≈ 75 hata yönetimi / çevrimdışı testi + önbellek, sorgu (Rules 3 yeni sorgu), tembellik ve çözme testleri; MGT-02 / 06 / 07 / 08 ve ADM-03 çevrimdışı yazma testleri (T-43 açığı kapandı).
8. **Kalan:** gerçek cihaz profil ölçümü + Crashlytics konsol doğrulaması (W-108, T-46); hatırlatıcı / çakışma denetiminde etkinlik başına okuma (veri modeli kararı); `flutter pub outdated` — güvenlik danışması yok, yükseltme T-45 sonrasına (`docs/reports/T-44-perf.md` §5).
