### 6.4 Sayaç eşleşmeleri (iki yönlü; `get` = işlem öncesi, `getAfter` = işlem sonrası)
| (Δgoing, Δwaitlist, Δattended) | rsvp geçişi | Dal |
|---|---|---|
| (+1, 0, 0) | yok \| `cancelled` → `going` | kendi |
| (0, +1, 0) | yok \| `cancelled` → `waitlist` | kendi |
| (−1, 0, 0) | `going` → `cancelled` | kendi |
| (0, −1, 0) | `waitlist` → `cancelled` | kendi |
| (0, 0, +1) / (0, 0, −1) | `going` ↔ `attended` | yönetici |
| (+1, −1, 0) | `waitlist` → `going` | yönetici |
- **Etkinlik sayaç dalı:** `touches(['goingCount','waitlistCount','attendedCount'])`, üçlü yukarıdaki 7 bileşimden biri, yazım-sonrası üçü de `>= 0`, `attendedCount <= goingCount`; **Δgoing == +1 ⇒ `resource.data.get('capacity', null) == null || request.resource.data.goingCount <= capacity`** (kontenjan aşımı burada reddedilir; W-51: anahtarsız = sınırsız). Kendi dalı: `r = getAfter(rsvps/{eventId}_{uid()})`, `r.eventId == eventId && r.userId == uid()`, geçiş `exists / get` ile. Yönetici dalı: `isManager(clubId) && activeUser()`, yan belge `getAfter(.../private/counter)` (`updatedAt == request.time`), `r = getAfter(işaretçi)`, `r.eventId == eventId`, işaretçi `== 'rsvps/' + eventId + '_' + r.userId`.
- **Rsvp dalı:** kendi sayacının işlemin tamamında tam ±1 oynadığını görür (`counterDelta(eventPath, …)`; terfide iki sayaç); yönetici dallarında ayrıca yan belgenin işaretçisi **bu** rsvp'dir. Tek başına sayaç ya da tek başına rsvp yazan işlem reddedilir; tek artışla iki rsvp yazılamaz (kendi dalında yol oturumdan, yönetici dalında tek işaretçi).
- İstemci sayaçları yalnızca `FieldValue.increment` ile yazar; etkinlik sayaç yazımı `updatedAt`'i de yeniler (`touches`).

### 6.6 Durum makinesi
`draft → published` (`startsAt > request.time`) · `published → draft` yalnız `goingCount == 0` (K-F aynen; bekleme listesi kayıtları kalır) · `published → cancelled` (+ neden) · `cancelled` terminal (içerik düzenleme, kayıt aç / kapa, katılım yok) · soft delete / restore yalnız `draft`. "Geçmiş" durum değildir: katılım `endsAt > request.time`, yoklama K-G penceresi, terfi `endsAt > request.time` ister.
