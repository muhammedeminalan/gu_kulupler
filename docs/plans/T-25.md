### b. Kimlik şeması (W-49, CD-129)
- `{type}_{eventKey}_{userId}` (`FirestoreIds.notification`). Dağıtıcı türlerinde `eventKey` = `NotificationWriter.newEventKey()` = Firestore otomatik kimliği (20 karakter `[A-Za-z0-9]`), **bir `notifyX` çağrısı = bir olay = bir anahtar**: olayın tüm alıcıları, tüm parçaları ve parça yeniden denemeleri aynı anahtarı kullanır (çift yazım aynı belgeye düşer, idempotent); olayın tekrarı (onayla → geri al → yeniden onayla, rol değişimi / devir, çıkar → geri al → çıkar, yeniden başvuru, yeniden yayın, terfi) yeni anahtar → yeni belge. Kritik batch transaction içinde yeniden koşarsa yalnızca kesinleşen denemenin belgesi kalır.
- `event_reminder`: `event_reminder_{eventId}_{uid}` (deterministik; `createSelf` önce tekil okur, varsa — silinmiş olsa da — yazmadan başarı).
- Gerekçe: W-49'daki `clubId + priorCount` önerisi geri al döngüsünde tutmaz (geri al `priorCount`'u artırmaz → aynı kimlik → kritik batch `permission-denied`). Tahmin edilemez anahtar ayrıca başka bir aktörün (ör. başka kulübün yöneticisi) gelecekteki kimliği önceden işgal edip kritik batch'i düşürmesini engeller.
- **Rules kimlik biçimini doğrular** (erişim çağrısı yok, yalnızca dizgi): dağıtıcı türlerinde `id == type + '_' + key + '_' + userId` ve `key.matches('^[A-Za-z0-9]{20}$')`; `event_reminder`'da tam eşitlik `'event_reminder_' + refs.eventId + '_' + uid()` (başka türün `event_reminder_…` kimliğini işgal etmesi engellenir).

### f. Rules — tür bazlı create (Mod C)
- **Ortak:** `activeUser()` · `baseCreate()` · `keys().hasOnly(['userId','type','refs','read','createdAt','updatedAt','isDeleted','deletedAt','deletedBy'])` · `read == false` · `userId is string && userId.size() > 0` · `refs` anahtarları 7'lik beyaz listede; türün zorunluları dolu dizgi (`role` rol değeri), diğerleri `refs.get(k, null) == null` (W-51) · kimlik biçimi (b).

- `announcement`: `isManager(c)` · `get(posts/{refs.postId})` → `clubId == c && type == 'announcement' && pushSent == true && isDeleted == false`. **Duyuru limiti:** gönderi oluşturma T-19 `announcementCounters` dalında zaten uygulanır; bildirim dalı yalnızca bildirimli duyurunun varlığını görür, ek kota yok (K-J).

- Diğer türler `false` (c tablosu).
