## 1. Kapsam
- **Sözleşme:** her yönetici yazımının batch / transaction içeriği; W-64 yönetici sayaç işaretçisi yan belgesi (`clubs/{id}/private/counter` — kulüp; `events/{id}/private/counter` — etkinlik, T-22'de açık); 30 sn geri al penceresi; hiyerarşi (başkan > yönetim kurulu > üye; danışman salt okunur); başkanlık devri tek batch; bildirim dalları (W-83).
- **A — gu_data:** `MembershipRepository` yönetici geçişleri (approve, reject, undoDecision, remove, undoRemoval, changeRole, transferPresidency) + bildirimler + activity aynı işlemde.
- **B — gu_data:** `ManagementRepository` (kompozisyon: gönderi yayın / sabitle, etkinlik yayın / iptal / taslak, kulüp ayarı güncelleme, bildirim dağıtımı) + `AttendanceRepository` (bilet okutma, elle yoklama, bekleme listesinden terfi; W-77, W-79).
- **C — Rules:** memberships M5–M13 (yönetici dalları), clubs yönetim alanları + yan sayaç belgesi, events / rsvps yönetici dalları, activity yönetici türleri, notifications approved / rejected / removed / role_changed dalları + testler + bütçe.

## 2. Testler (kritik)

### b. W-64 — yan sayaç belgesi

- **Kulüp:** `clubs/{clubId}/private/counter` = `{clubId, lastMembershipRef: 'memberships/{c}_{u}', updatedAt}` (BaseFields yok), `set` (birleştirme yok), yalnızca yönetici / süper admin aktörlü `memberCount` geçişiyle **aynı Tx**'te.
