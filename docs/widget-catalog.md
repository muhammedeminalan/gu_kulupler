> Faz 1 iskeleti (D-16). Yeni widget yazmadan önce bu dosya ve `docs/design-analysis.md §A/§G` taranır; benzeri varsa **genişletilir**, ikinci gövde açılmaz. Her task kendi satırlarını aynı commit'te `planned → done (T-xx)` / `changed (T-xx)` yapar (PLAN §8.4.1). Satır sırası `design-analysis.md §A.1` numarasıyla (1-63 şablon, 64-81 A.1 ekleri; 72 ve 74 bilinçli boşluk, CD-102), ardından `ek-N` = A.1 tablosunda satırı olmayan yardımcı/sarmalayıcı sınıflar (PLAN §8.4.1). Durum matrisleri `design-analysis.md` A.2 "Durumlar" sütunundan (CD-82).
>
> Sütunlar: **Widget** sınıf adı · **Konum** dosya yolu (repo köküne göre) · **Durum** `planned | done (T-xx) | changed (T-xx)` · **Task** ilk yazıldığı task · **Tasarım ID'leri** kullanıldığı ekran/sheet/dialog (`css-class-usage.json` + kaynak blok taraması, `scratchpad/faz1/component_ids.json`) · **Prototip** `ui.js`/`cards.js` adı ve CSS sınıfları · **Durum matrisi** D default · P pressed · F focus · X disabled · L loading · S selected · E error · R read-only · — statik (yalnızca CSS/görüntü kanıtlı olanlar) · **Varyant / parametre** · **Test** dosyası · **Golden** dosyaları · **Not** K-xx / CD-xx.
>
> Özet: **gu_ui: 71 · product: 23 · feature-local: 9** — T-03 ile 5'i `done` (#45 `GuIcon`, #48 `GuLogo`, #49 `GuCover`, #50 `GuIllustration`, #76 `GuEmblem`; widget başına golden yok, CD-123), kalanı `planned` (Faz 1 inceleme: F10 `AnnouncementQuotaBar` → P23, CD-109; F11 `MgtKpiGrid` kaldırıldı, CD-112).
